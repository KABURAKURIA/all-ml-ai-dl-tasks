# AI Inference Notebooks & Tools

This repository contains a comprehensive collection of **55+** Jupyter Notebooks and generated Python tools for AI/ML inference. The content covers a wide range of domains including Computer Vision, Natural Language Processing, Audio, Multimodal tasks, Reinforcement Learning, and Tabular data.

## 🚀 Key Features

*   **Google Colab Optimized**: All notebooks are optimized to run on the **Google Colab Free Tier** (T4 GPU).
*   **Beginner to Advanced**: Covers everything from basic classification to advanced topics like Agents, RAG, and LLM Fine-Tuning.
*   **Practical & Hands-on**: Uses real-world models (Hugging Face transformers, diffusers, etc.) and real datasets.
*   **Zero-Setup**: "Click and Run" experience with all necessary installations included.

## 📂 Directory Structure

*   **`ai_inference_notebooks/`**: Contains the Jupyter Notebooks.
    *   **Audio**: ASR (Whisper), TTS, Music Generation.
    *   **CV**: Stable Diffusion, Object Detection, Segmentation, Video Generation.
    *   **Multimodal**: VQA, Captioning, Document Analysis, Vision Language Chat.
    *   **NLP**: LLMs (SmolLM2), RAG, Agents, Translation, Summarization.
    *   **RL & Tabular**: Reinforcement Learning and Tabular data tasks.
*   **`psychology_inference_tools/`**: Contains generated Python scripts for specific psychology domains.
*   **`manuals/`**: User documentation and catalogs.

## 🛠️ Usage

1.  Navigate to `ai_inference_notebooks/` to explore the notebooks.
2.  Open any `.ipynb` file in Google Colab or a local Jupyter environment with GPU support.
3.  Run the cells sequentially. The first cell always handles dependency installation.
