# AI Inference Notebooks

This folder contains a comprehensive set of Jupyter Notebooks designed to introduce you to AI and Machine Learning tasks using open-source models.

**No programming experience is required!** The notebooks are heavily documented and explain every step.

## How to use

1.  Open these notebooks in a Jupyter environment (like JupyterLab, VS Code with Jupyter extension, or Google Colab).
2.  Start with `01_Setup_and_Introduction.ipynb`. It will guide you through installing the necessary tools.
3.  Proceed through the notebooks based on your interest:

    *   **Core Concepts**: `02_NLP_Essentials.ipynb`, `03_NLP_Advanced_and_LLMs.ipynb`
    *   **Images & Vision**: `04_Computer_Vision_Analysis.ipynb`, `05_Computer_Vision_Generation.ipynb`
    *   **Combined**: `06_Multimodal_and_Documents.ipynb`
    *   **Audio**: `07_Audio_Processing.ipynb`
    *   **Other**: `08_Tabular_and_Reinforcement_Learning.ipynb`

## Covered Tasks

*   Text Classification (Sentiment Analysis)
*   Token Classification (Named Entity Recognition)
*   Question Answering
*   Summarization
*   Translation
*   Zero-Shot Classification
*   Text Generation (LLMs)
*   Fill-Mask

*   Feature Extraction

### Computer Vision (CV)
*   Image Classification
*   Object Detection
*   Image Segmentation

*   Text-to-Image (Stable Diffusion)
*   3D Generation (Code example)

### Multimodal
*   Image Captioning (Image-to-Text)
*   Visual Question Answering (VQA)
*   Document Question Answering

### Audio
*   Automatic Speech Recognition (ASR)

*   Text-to-Speech (TTS)

### Other

These notebooks rely on Python and several libraries, mainly:
- `transformers`
- `diffusers`
- `torch`
- `sentence-transformers`
- `stable-baselines3`

The first notebook will help you install them.
